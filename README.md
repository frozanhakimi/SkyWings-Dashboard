# SkyWings Airlines Dashboard

## About the Project

SkyWings Airlines Dashboard is an airline web project created using HTML, CSS, and JavaScript. It includes a dashboard, navigation sidebar, flight information, booking information, and a login page.

## Installation

No special installation is required.

1. Download or clone the project.
2. Open the project folder.
3. Open `dashboard.html` in a web browser.
