# ✈️ SkyWings Airlines Dashboard

A responsive airline dashboard website built with **HTML, CSS, and JavaScript**.

## Features

* Dashboard overview
* Find Flights and flight search
* My Bookings
* Booking confirmation and cancellation
* E-ticket display
* List/Grid flight view
* Login page
* Responsive design

## Technologies

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## Project Structure


## How to Run

Open `Dashboard.html` in a browser or use **Live Server** in VS Code.
